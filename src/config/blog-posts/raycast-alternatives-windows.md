## Windows

Raycast's Windows version is still in beta (more on that [below](#s-what-about-raycast-for-windows)), and meanwhile Windows has quietly built its own launcher tradition.

### PowerToys Command Palette (Microsoft)

The successor to PowerToys Run, Command Palette is Microsoft's own take on the launcher — free, open source, and installed alongside the rest of the PowerToys suite.

**What it's best at:** being the safe default. It launches apps, does math, converts units, searches files, and it's maintained by Microsoft, so it will never be abandoned or start charging you. If you just want "Spotlight on Windows" with zero risk, start here.

**Where others beat it:** it's utilitarian by design. The extension ecosystem is younger and smaller than Flow Launcher's, the UI is functional rather than fast-feeling, and like every classic launcher it's stateless — it knows nothing about what you're working on.

### Flow Launcher

Flow Launcher is the community's launcher: open source, free, and with the largest plugin ecosystem on Windows — everything from Everything-powered file search to clipboard history, window switching, and developer utilities.

**What it's best at:** being Raycast-shaped. If what you loved about Raycast was the plugin culture — install a community extension for every tool you use — Flow is the closest Windows equivalent, and the Everything integration makes its file search extremely fast.

**Where others beat it:** it rewards tinkering and expects some. Plugin quality varies, setup takes an evening to get right, and out of the box it's less polished than Command Palette. It's also Windows-only. Like the others, every search starts from zero.

### Fluent Search

Fluent Search is the tool people most often recommend when someone asks for "Raycast on Windows" — and it's easy to see why. It's free (donation-supported), keyboard-first, and searches far more than apps: files, open windows, browser tabs, history and bookmarks, and even text visible on your screen.

**What it's best at:** breadth of search. Its screen search lets you click buttons and links by typing instead of reaching for the mouse — something no other launcher here does — and its browser integration means tabs show up next to apps and files. If you want one search box that reaches into everything, start here.

**Where others beat it:** it's dense. There are a lot of settings and result types to tune, and the defaults can feel busy until you do. Its plugin ecosystem is smaller than Flow Launcher's, and like the rest of this list it searches what exists *now* — it doesn't remember which things belong to which project.

### Listary

Listary is the veteran of this list, and it has one killer feature nobody else has: it lives inside your file dialogs. Hit a key in any Open/Save dialog and Listary finds the folder you need instantly — a daily-pain fix that no other launcher touches.

**What it's best at:** files. If your day is spent navigating deep folder trees, opening and saving into project directories, Listary's find-as-you-type search (free version included) will save you more clicks than any launcher on this list.

**Where others beat it:** it's a file tool first and a launcher second. Commands, plugins, and app-launching exist but aren't the point, and the Pro license (one-time purchase) is where the best features live.

### Keypirinha

Keypirinha is the keyboard purist's choice: a tiny, portable, blazingly fast launcher configured entirely through text files.

**What it's best at:** speed and control. There is no UI to fight — you define exactly what it indexes and how it behaves, and it starts instantly from a USB stick if you want.

**Where others beat it:** everywhere that isn't speed and control. Configuration-by-text-file is a feature for its audience and a wall for everyone else, and development has slowed in recent years. Choose it if editing an INI file sounds fun, not if it sounds like work.

## Mac

Raycast is at its best on the Mac, so the bar here is high. These are the tools people actually switch to — usually to avoid a subscription, or because they want something lighter.

### Alfred

Alfred is the launcher Raycast grew up competing with, and it's still the favourite of a lot of long-time Mac power users.

**What it's best at:** workflows without a subscription. The free version is a fast, clean launcher; the Powerpack (a one-time purchase) unlocks clipboard history, snippets, and Workflows — visual automations you can build yourself or install from a large community library. If Raycast's Pro pricing is what's pushing you away, Alfred is the obvious landing spot.

**Where others beat it:** it feels more traditional than Raycast. There's no built-in extension store in the same sense, AI features are something you add yourself rather than a core part of the product, and the best parts sit behind the Powerpack. It's Mac-only.

### LaunchBar

LaunchBar has been around for well over a decade and has a quietly devoted following.

**What it's best at:** learning you. Instead of fuzzy-matching every time, it learns the abbreviations you actually type and adapts its results to them, which makes it extremely fast once it knows your habits. It also does clipboard history, snippets and file actions well.

**Where others beat it:** it's paid (a one-time licence, with a free trial), the community around it is smaller than Alfred's or Raycast's, and its interface has a learning curve. It's Mac-only.

### Spotlight (built in)

Don't skip the one you already have. With macOS 26 Tahoe, Apple gave Spotlight its biggest upgrade in years: it can now run actions inside apps, keep a clipboard history, and trigger commands with short "quick keys".

**What it's best at:** being there. No install, no settings, no third-party trust — and for launching apps, finding files and doing simple actions, it's now genuinely good.

**Where others beat it:** extensibility. There's no community extension store, workflows are limited to what Apple and app developers expose, and power users will still hit its ceiling quickly.

## Linux

Raycast doesn't exist on Linux at all, so this is where alternatives matter most. The good news: Linux launchers are free, open source, and better than their reputation.

### Ulauncher

Ulauncher is the most commonly recommended launcher for GNOME and Ubuntu users, and for good reason.

**What it's best at:** approachability. It installs from most distro repos, looks clean out of the box, and has a sizeable library of community extensions written in Python — so it's easy to add exactly what you need, or write it yourself.

**Where others beat it:** speed and polish on very large indexes, where Albert feels snappier. Extension quality varies, and some popular ones lag behind the latest release.

### Albert

Albert is a fast, native launcher built in C++ and Qt, with plugins for apps, files, calculators, web search, clipboard and more.

**What it's best at:** feeling instant. It's light on resources, consistent across desktop environments, and its built-in plugin set covers most needs without hunting for third-party extensions.

**Where others beat it:** the plugin ecosystem is smaller than Ulauncher's, and theming and configuration are less friendly for newcomers.

### KRunner (built in)

If you use KDE Plasma, you already have a capable launcher: press Alt+Space and KRunner appears.

**What it's best at:** integration. It searches apps, files, settings, open windows and more, runs calculations and unit conversions, and plugs into the rest of Plasma — no install required.

**Where others beat it:** outside KDE it isn't really an option, and it's a launcher only — no extension store in the Raycast sense.

### Vicinae

Vicinae is the newest tool on this list: an open-source launcher for Linux that deliberately borrows Raycast's design and command model.

**What it's best at:** feeling like Raycast. If you've moved from a Mac to Linux and miss Raycast specifically, this is the closest you'll get, and it aims to run a growing share of Raycast's own extensions.

**Where others beat it:** maturity. It's young, moving fast, and you should expect rough edges and breaking changes that Ulauncher and Albert left behind years ago.

## CoolDesk (that's us)

CoolDesk is a free, open-source launcher for **Windows, macOS and Linux** with a different core idea: it's built around your **projects**, not just your apps.

**What it's best at:** context, on every machine you use. Every other tool on this list is stateless — brilliant at opening things, but with no idea that *this* browser tab, *that* Figma file, and those three VS Code windows all belong to the same piece of work. CoolDesk groups tabs, apps, links and notes into project workspaces: press Alt+K to find anything, or switch projects and everything comes back exactly where you left it. Its browser extension also makes your open tabs, history and bookmarks first-class search results, grouped by the project they belong to. And because it runs on all three platforms, the same habit works whether you're on a Windows work laptop, a Mac at home or a Linux desktop. It's free, needs no account, and keeps all data on your device.

**Where others beat it:** maturity and breadth. We're one of the youngest tools here. Flow Launcher and Alfred have a plugin or workflow for everything; we don't have a plugin store. Command Palette and Spotlight have Microsoft and Apple behind them; we're an indie project. Fluent Search's screen search has no equivalent in CoolDesk, and Listary's file-dialog integration is unique and we don't do it. And we don't have text expansion — if that's core to your workflow, pair CoolDesk with one of the tools above (they coexist happily; different hotkeys).

## What about Raycast for Windows?

It's real, and it's improving fast. Raycast opened a public beta for Windows in late 2025, and as of November 2026 it's still labelled beta. The core is there — the command palette, clipboard history, snippets, window management and AI commands all work — but the Windows extension store is a fraction of the size of the Mac one, and some Mac integrations have no Windows equivalent yet. There is no Linux version.

The pricing model is the same on both platforms: the launcher is free, and the best AI features, cloud sync and some extras sit behind a Pro subscription that covers Mac and Windows together.

**Our honest take:** if you're moving from a Mac and want the exact same muscle memory, install the beta and see how far it gets you. If you're Windows-first, the Windows tools above are mature today, free, and built around how Windows works — no waiting required.

## FAQ

**What's the best free Raycast alternative?**
It depends on your OS. On Windows: Flow Launcher for plugins, Fluent Search for searching everything, PowerToys Command Palette as the safe default. On Mac: Alfred's free version or Spotlight. On Linux: Ulauncher or Albert. On all three, for project-based work across apps and browser tabs: CoolDesk. All of these are free.

**Is there an open-source Raycast alternative?**
Yes — plenty. Flow Launcher, PowerToys Command Palette and Fluent Search on Windows; Ulauncher, Albert, KRunner and Vicinae on Linux; and CoolDesk on Windows, Mac and Linux are all open source.

**Is Raycast available on Windows?**
Yes, as a public beta since late 2025. It works, but it has far fewer extensions than the Mac version.

**Is Raycast available on Linux?**
No. Vicinae is the closest Raycast-style launcher on Linux; Ulauncher and Albert are the most established options.

**Is there a Raycast alternative that works on Windows, Mac and Linux?**
CoolDesk runs on all three. Ueli covers Windows and Mac. Raycast itself covers Mac and (in beta) Windows, but not Linux.

**Raycast vs Flow Launcher — which is better?**
On Windows today, Flow Launcher is more mature and has a far bigger Windows plugin library; Raycast has the more polished interface and built-in AI. On Mac, Flow Launcher isn't an option — it's Windows-only.

**Can I run two launchers at once?**
Yes — just give them different hotkeys. A common setup is a launcher for apps and commands plus Listary or Everything for files.

Whichever you choose, the real upgrade is the habit: one keystroke instead of hunting through menus and forty tabs. Every tool on this list delivers that. The differences are about what happens *after* the keystroke.
