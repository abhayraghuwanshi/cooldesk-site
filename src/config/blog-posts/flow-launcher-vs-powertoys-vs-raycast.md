# Flow Launcher vs PowerToys vs Raycast on Windows (2026)

Flow Launcher, PowerToys Command Palette and Raycast for Windows, compared head to head: speed, plugins, file search, AI, price and which one to install.

If you've narrowed your Windows launcher down to three names, they're almost always these: **Flow Launcher**, the community favourite; **PowerToys Command Palette**, Microsoft's own (the successor to PowerToys Run); and **Raycast**, the Mac favourite that now has a Windows beta. All three open with one shortcut, find apps and files, do quick maths and run commands. The differences are in what's around that core.

Full disclosure: **we make a launcher too** (CoolDesk). It isn't one of the three, so we've kept it to one short section at the end. For each of the three, we say what it's best at *and* where the others beat it.

## Flow Launcher

Flow Launcher started as a fork of Wox and became the most popular open-source launcher on Windows. You press Alt+Space, type, and pick a result. What makes it Flow is the plugin store: hundreds of community plugins you install from inside the launcher by typing `pm install`.

**What it's best at:** depth. There's a plugin for window switching, clipboard history, Steam games, VS Code projects, browser bookmarks, currency conversion, Spotify, Windows settings and much more. Paired with [Everything](https://www.voidtools.com/), its file search is close to instant even on huge drives. Themes, result ranking and hotkeys are all configurable.

**Where the others beat it:** polish and setup time. Out of the box it's plainer than Raycast, and getting it just right takes an evening of trying plugins, whose quality varies. Microsoft won't keep it going the way it will Command Palette; it depends on volunteers (who have been reliable for years). And it's Windows-only.

## PowerToys Command Palette

Command Palette is the launcher inside Microsoft PowerToys, the free, open-source toolkit that also gives you FancyZones, Color Picker and Text Extractor. It replaces the older **PowerToys Run**: Run is still in the suite for now, but Microsoft's work has moved to Command Palette. Open it with Win+Alt+Space.

**What it's best at:** being the default nobody regrets. It launches apps, searches files, does maths and unit conversions, switches windows, runs terminal commands and opens Windows settings. Extensions are installed through WinGet, so they come from the same place as other Windows software. It's maintained by Microsoft, so it won't be abandoned or start charging.

**Where the others beat it:** personality and breadth. The extension catalogue is much younger than Flow's, the interface is functional rather than delightful, and it comes as part of a whole suite: you install PowerToys to get it, though you can switch the other tools off.

**Flow Launcher or PowerToys?** If you'd never install a plugin, take Command Palette: less to set up, and it'll be there in five years. If you'd install three plugins in the first week, take Flow.

## Raycast for Windows

Raycast is the launcher most Mac power users switched to over the last few years, and its Windows version opened as a public beta in late 2025. As of November 2026 it's still labelled beta.

**What it's best at:** the experience. It's the most polished of the three to look at and use, with clipboard history, snippets, window management, quicklinks and AI commands built in, not added by plugin. If you use a Mac too, the same shortcuts and habits carry over, and Pro covers both platforms.

**Where the others beat it:** maturity on Windows. The Windows extension store is a fraction of the Mac one and far smaller than Flow's plugin library, and some Mac features have no Windows equivalent yet. It's closed source, and its headline AI features and cloud sync need a Pro subscription. The other two are completely free.

**Flow Launcher or Raycast?** On Windows today, Flow is more mature and has far more plugins. Raycast feels better and has AI built in. If you're coming from Raycast on a Mac, try the beta first. If you're Windows-first, start with Flow.

## Head to head

**Speed.** All three feel instant for apps. For files, Flow with Everything is the fastest; Command Palette and Raycast are fine for normal folders.

**Plugins.** Flow, by a long way. Command Palette second and catching up; Raycast's Windows store is the smallest of the three for now.

**Looks and polish.** Raycast, then Flow (with a theme), then Command Palette.

**AI.** Raycast has it built in, with Pro. Flow and Command Palette can call ChatGPT, Claude or local models through community plugins or extensions, set up by you.

**Price.** Flow and Command Palette are free and open source. Raycast's launcher is free; AI, sync and some extras are a subscription.

**Trust and longevity.** Command Palette has Microsoft behind it. Flow has years of steady volunteer releases. Raycast is a funded company, still in beta on Windows.

## Which one should you pick?

- **"I want it to just work, and still be there in five years"** → PowerToys Command Palette
- **"I want a plugin for everything I use"** → Flow Launcher
- **"I'm coming from a Mac and miss Raycast"** → Raycast for Windows (beta)
- **"I want the fastest file search"** → Flow Launcher with Everything
- **"I want AI in my launcher without setting it up"** → Raycast Pro
- **"I don't want to pay, ever"** → Flow Launcher or Command Palette

You can also run two at once with different shortcuts. A common setup is Command Palette for apps and Flow (or Listary) for files.

## FAQ

**Is Flow Launcher better than PowerToys Run?**
For most people who want plugins, yes. Flow has a much larger plugin library and faster file search with Everything. PowerToys Run itself is being replaced by Command Palette, which is the better comparison now.

**Is PowerToys Run discontinued?**
Not removed yet, but Microsoft's launcher work has moved to Command Palette, which does everything Run did and more. New setups should use Command Palette.

**Is Raycast available on Windows?**
Yes, as a public beta since late 2025. It works well for the basics but has far fewer extensions than on Mac.

**Raycast vs Flow Launcher: which is better?**
On Windows today, Flow Launcher is more mature and has far more plugins. Raycast is more polished and has AI built in. On a Mac, only Raycast is an option; Flow is Windows-only.

**Raycast vs PowerToys: which should I use?**
PowerToys Command Palette if you want free, open source and maintained by Microsoft. Raycast if you also use a Mac or want built-in AI and are fine with a beta.

**Are these launchers free?**
Flow Launcher and PowerToys Command Palette are completely free and open source. Raycast's launcher is free, with a Pro subscription for AI, sync and extras.
